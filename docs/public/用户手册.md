# EspNav 用户手册

> 面向**使用者**：怎么装、怎么连、怎么用、出问题怎么办。
> 想改代码请看 [开发指南](../develp/开发指南.md)；想看文档全貌看 [README](../../README.md)。

**适用版本**：v1.1.0（固件 `V1.1.0` / App `1.1.0`）

---

## 1. 这东西能干什么

骑自行车/电动车时，把手机导航的关键信息投到车头一块 **2.8 寸小屏**上：

| 屏幕上有什么 | 说明 |
| :--- | :--- |
| **路面 + 转向提示** | 前方要直行/左转/右转/环岛，以及还有多少米 |
| **罗盘方位** | 车头朝向（8 方位）+ 精确角度 |
| **行程图** | 右上角整条路线的缩略图 + 你的位置（黄点） |
| **行程统计** | 全程 / 已完成百分比 / 已耗时 / 预计到达时间 |
| **道路名**、**网络状态** | 滚动显示 |

手机端 App 同时提供：地图选点、路线预览、**导航画面**（相机跟随车头、已走灰/未走蓝、行程图卡片）。

## 2. 需要准备什么

| 项 | 要求 |
| :--- | :--- |
| 显示终端 | **quandong-s3-dev** 板（ESP32-S3 + 2.8″ ILI9341 320×240 SPI 屏 + FT6336G 触摸） |
| 电脑 | Windows + **ESP-IDF v6.1**（装在 `E:\esp\v6.1`，用 "IDF PowerShell Environment" 启动） |
| 手机 | Android；本项目在 **Huawei Mate 40 Pro / HarmonyOS 4** 实测通过 |
| 高德 Key | 在高德开放平台申请，**必须开通「Android 导航 SDK」**（只开通"地图 SDK"会导致算路失败），包名填 `com.espnav.app`，SHA1 用你签名 APK 的那个 |
| 网络 | 真实导航需要**外网**（App 要调高德服务器算路） |

### 硬件接线（出厂即焊好，核对用）

| 信号 | GPIO |
| :--- | :--- |
| SPI SCK | 12 |
| SPI MOSI | 11 |
| LCD DC | 46 |
| LCD CS | 10 |
| 背光 BL | 45（高有效） |
| MISO / RST | **无** |

> 完整板级参数（MADCTL=0xA0、40MHz、INVON）见 [实施方案](../develp/实施方案.md)。

## 3. 烧固件（ESP32-S3）

```powershell
cd D:\example\projects\Esp32Nav\v1.0.0.1\Esp32S3
idf.py -p COM3 build flash monitor
```

- `COM3` 换成你的串口号（设备管理器里看）
- 烧完屏幕应显示开机画面 **`EspNav v1.1`**，随后进入「请在 App 开始导航」的等待画面

> 若烧录失败（`No serial data received`）：先查串口是否被别的程序占用，再按住板上的 `BOOT` 键重新上电进下载模式。

## 4. 安装 App

**方式 A（推荐，图省事）**：直接把仓库里的 APK 拷到手机安装

```
mobileApp/android/espnav-debug.apk        （约 121 MB）
```

**方式 B（自己编译）**：

```bash
cd mobileApp/android
export JAVA_HOME="$HOME/.jdks/jbr-17.0.14"     # Gradle 7.6.6 不兼容 JDK 25
./gradlew --no-daemon :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

首次打开需要授权：**定位权限**（算路要用）。

## 5. 连接 ESP32

### 情况一：先用起来（不需要外网）

1. 手机 WLAN 里连上 ESP32 的热点 **`ESPNav-AP`**（默认密码见设备说明，无密码则直接连）
2. 打开 App → 点「**一键连接**」→ 它会自动在候选地址里找到 `192.168.4.1`
3. 连上后，连接页会显示「已连接」，日志区出现 `HELLO_ACK` / `DEV_STATUS`

> 此时手机没有外网，**只能看 App 里的模拟导航**，真实算路会失败（这是正常的）。

### 情况二：真实导航（需要外网）—— 把 ESP32 配到你手机热点

1. 手机打开**自己的热点**（2.4GHz）
2. 手机仍连着 `ESPNav-AP`，用浏览器打开 **`http://192.168.4.1`**
3. 在配网页搜索并选择**你刚才开的热点**，填密码，保存
4. ESP32 会去连你的热点（屏幕上 STA 状态变为已连接）
5. 手机切回自己的热点 → App 里「一键连接」（IP 可能是 `192.168.x.x`，可点「扫描设备」自动发现）

> ESP32 最多保存 3 组 WiFi 凭据，会自动选连；换路由不需要重配。

## 6. 日常使用

### 6.1 连接页

| 按钮 | 作用 |
| :--- | :--- |
| 一键连接 | 自动尝试候选地址连接 |
| 扫描设备 | 在当前网段里扫 8899 端口找 ESP32 |
| 断开 | 断开连接（App 会记住是你主动断的，不会自动重连） |
| 打开配网页 | 跳浏览器打开 `http://192.168.4.1` |
| **⚙ 设置** | 见 §7 |

### 6.2 导航页

1. **定起终点**：
   - 方式一：**在地图上点一下**（长按更灵敏）→ 弹窗选「设为起点 / 设为终点」
   - 方式二：点「编辑」展开输入框，**输入地址文字**
   - 终点与起点不能同时为空
2. **预览路线**：点「预览路线」→ 地图上出现蓝色路线 + 起点/终点标记，状态栏显示「全程 x.x km · 预计 y 分钟」
   > 预览**不会**发给 ESP32，是让你先确认
3. **开始导航**：点「开始导航」→ 地图切换成**导航画面**，同时 ESP32 屏开始实时刷新
   - 相机跟随车头（地图随行进方向旋转、45° 俯视）
   - 路线**已走灰、未走蓝**，车头黄色箭头
   - 右下角**行程图卡片**：整条路线 + 当前位置黄点
   - 顶部信息条：转向提示 + 剩余里程/预计分钟 + 「**结束导航**」
4. **结束导航**：点顶部「结束导航」→ 停止推流、恢复正北视角（ESP32 保留最后一帧画面）

### 6.3 行程预览页（第 3 个 Tab）

算过路线后切到它，会看到**同一条路径**用两种采样算法画出来的行程图并排对比：

| 侧 | 算法 | 特点 |
| :--- | :--- | :--- |
| 左 | **Visvalingam**（面积删点 + 直角锁定） | 默认。长而缓的弧线优先保留，长直段不浪费点 |
| 右 | **Douglas-Peucker**（自适应 ε） | 误差有界，但长缓弧在极端压缩下会被拉直 |

每侧还会显示：输出点数、相对原路径的最大偏差（px / 米）、耗时。
电脑上双击 `mobileApp/android/app/src/main/assets/sampling_compare.html` 也能打开（内置演示数据）。

## 7. 设置项说明

打开方式：连接页 →「⚙ 设置」

| 分组 | 项 | 说明 |
| :--- | :--- | :--- |
| **连接** | 设备地址 / 端口 | 默认 `192.168.4.1` / `8899`；连上过会自动记住 |
| | App 启动后自动连接一次 | 默认**关**（避免你手动断开后被强行连上） |
| **导航默认** | 默认起点 / 终点地址 | 留空则用当前定位 |
| | 自动使用当前城市 | 开着更省事（地址解析用） |
| | 地理编码城市 | 关掉自动时手动填，如 `北京` |
| | **导航仿真（模拟行进）** | **默认开** —— App 让高德按路线"模拟跑"，室内就能看效果；**上路实测前必须关掉**，否则屏幕不跟你的真实位置 |
| **地图** | 默认缩放级别 | 10~19，16 较近、11 约 20 公里 |
| **行程图** | 采样算法 | Visvalingam（高保真，推荐）/ Douglas-Peucker |
| **ESP 显示元素**（排查用） | 一键全关 / 道路图案 / 车道中线 / 行程图 / 车头三角 | 逐个关掉可以定位 ESP 屏幕上"哪条线是谁画的"；平时全开 |
| **日志** | 最多保留行数 | 默认 1000 |
| **权限** | 权限状态 + 前往系统设置 | Android 不允许 App 自己改权限 |
| **配置文件** | 见 §8 | |

## 8. 配置文件（卸载重装不丢设置）

设置存在**手机公共下载目录**：

```
/sdcard/Download/EspNav/espnav_config.json
```

| 操作 | 说明 |
| :--- | :--- |
| **授予「所有文件访问」权限** | Android 11+ 首次需要点这个按钮 → 在系统设置里打开 → 返回（只需一次） |
| **保存配置到文件** | 把当前 16 项设置写进上面那个文件 |
| **从文件恢复配置** | 从文件读回来 |
| **删除配置文件** | 带确认提示；删掉后卸载重装就不再保留 |

**行为**：App 每次启动会检查该文件，若存在会弹窗问「**是否用它覆盖当前设置？**」→ 点「覆盖」即恢复。

> 所以换手机、重装 App，只要那个 json 还在，就不用重新配置。

## 9. 常见问题

| 现象 | 原因 / 处理 |
| :--- | :--- |
| **一键连接连不上** | ① 手机没连 `ESPNav-AP`；② ESP32 没上电/没烧固件；③ 地址变了 → 点「扫描设备」或手动填 IP |
| **算路超时（12 秒）** | ① 高德 Key **没开通「Android 导航 SDK」**（只开地图 SDK 会这样）；② 手机**没有外网**（还连着 ESPNav-AP 热点）；③ 起终点太近或无骑行路径 |
| **"设置了途经点就超时"** | 高德的**骑行途经点算路是收费接口**，未开通时调用不返回 → 本项目已把该功能置灰；需要就通过高德工单申请 |
| **点「开始导航」没反应（第二次启动）** | 已在 v1.1.0 修复（高德 SDK 单例的初始化回调只触发一次）。请确认用的是 v1.1.0 之后版本的 App |
| **地图一片淡蓝** | 定位无效或没网，地图瓦片加载不出来 → 检查定位权限与网络 |
| **切到连接页后地图还盖在上面** | 已在 v1.1.0 修复（改用 `TextureMapView`） |
| **ESP 屏不刷新 / 显示"等待 App"** | ① 连接断了（超过 5 秒没收到帧，固件会自动回到等待画面）；② App 没点「开始导航」；③ 看 App 日志区有没有报错 |
| **ESP 屏上有多余的线** | 用设置里的「ESP 显示元素」逐个关掉定位是哪一类；正常情况下主视图只有道路图案 + 罗盘 + 文字 |
| **行程图不真实 / 拐弯画错** | 设置 → 行程图采样，可切换 Visvalingam / Douglas-Peucker 对比；也可在「行程预览」页看两种效果 |
| **开机画面版本号** | 应是 `EspNav v1.1`；若不是说明固件没烧成功 |

## 10. 上路实测前检查清单

- [ ] 设置 → **关掉「导航仿真（模拟行进）」**（否则不跟真实位置）
- [ ] 手机**有外网**（连着能上网的热点/流量）
- [ ] 高德 Key 已开通「Android 导航 SDK」
- [ ] 手机把本 App 加入**电池优化白名单**（否则熄屏后可能被系统杀掉，屏幕停止更新）
- [ ] 起终点已确认（点「预览路线」看一眼路线对不对）
- [ ] ESP32 屏幕显示正常（等待画面 → 开始导航后切换）
