# EspNav 连接与联调手册（v1.0 · 2026-09-15）

> 目标：3 分钟让手机控制 ESP32 外置导航屏；再花 2 分钟完成配网，让手机保持联网。

## 0. 先分清两个“连接”（大多数困惑都在这里）
| # | 谁连谁 | 作用 | 地址 |
| :--- | :--- | :--- | :--- |
| ① | **手机 → ESP32**（手机连热点 `ESPNav-AP`） | 打开配网页 / 用 App 控制屏幕 | `192.168.4.1:8899` |
| ② | **ESP32 → 手机热点**（配网的目地，STA 模式） | 让手机**保持上网**的同时仍能控制屏幕 | ESP32 从手机热点取得的 IP |

`ESPNav-AP`（密码 `espnav1234`）是 ESP32 自己开的热点，**它没有外网**；所以只连它时手机不能上网 —— 这正是需要配网（②）的原因。

---

## 1. 最快路径：不配网，手机直连（3 分钟见效）
1. 手机安装 APK：仓库内 `mobileApp/android/espnav-debug.apk`（允许“未知来源”）
2. 手机 **WiFi 连接 `ESPNav-AP`**（密码 `espnav1234`）
   - 华为/鸿蒙提示“此网络无法访问互联网”→ 选 **保持连接**
3. 打开 App「EspNav 控制器」→ 点 **「一键连接」**
   - App 会自动尝试 **上次成功的地址** → **`192.168.4.1`**，逐个探测直至连上
4. 日志区出现 `← DEV_STATUS 亮度=80 速度=40 …` = **连接成功**
5. 点 **「开始模拟导航」** → 屏幕按 7 个阶段循环（直行→弯道→T口→十字→环岛→多岔→匝道）
   - 也可用：**发送一帧** / **清屏** / 背光与速度滑杆 / 流动动画开关

> 该方式下手机无外网，仅适合调试；正式使用请做第 2 节的配网。

---

## 2. 配网：让手机既能上网、又能控制屏幕
1. **手机开热点，必须 2.4GHz**
   - 华为：设置 → 移动网络 → 个人热点 → **AP 频段 = 2.4GHz**
   - iPhone：设置 → 个人热点 → 打开 **“最大兼容性”**
2. 手机连 `ESPNav-AP` → 点 App 里的 **「打开配网页」**（或浏览器输入 **`http://192.168.4.1`**）
3. 点 **「搜索附近 WiFi」** → 在列表里**点选你的手机热点**（避免手输错）→ 输入密码 → **「保存并连接」**
4. 成功标志（任一）：
   - 串口日志：`wifi_sta: STA 连接成功 IP=192.168.x.y`
   - 配网页 `/status`：`{"sta_connected":true,"ip":"192.168.x.y", ...}`
5. 手机**切回自己的热点**（恢复上网）→ App 里点 **「一键连接」**（会自动尝试上次 IP）→ 连接后即可控制屏幕

> 最多保存 3 组网络，按最近使用顺序自动尝试；连续失败 3 次后改为 30 秒重试一次（避免 ESP32 自身热点抖动）。

## 3. 常见现象对照表
| 现象 | 原因 / 处理 |
| :--- | :--- |
| `wifi_sta: STA 断开: reason=201 (找不到热点…)` | 热点名写错，或该热点是 5GHz（ESP32 只支持 **2.4GHz**） |
| `reason=15 / 205 (认证失败/握手超时)` | 密码错 |
| 手机在 `ESPNav-AP` 上频繁掉线 | ESP32 单射频：STA 反复重试会带着 AP 换信道；改为正确热点名或等待退避后即稳定 |
| `httpd_uri: URI '/favicon.ico' not found` | 浏览器自动请求图标，无害 |
| App 点「连接」无反应 | 确认手机已连 `ESPNav-AP`；用「一键连接」；或先在浏览器确认能打开 `192.168.4.1` |
| 屏幕不动 | 先「发送一帧」确认链路；再「开始模拟导航」；屏幕端虚线动画由设备自行驱动 |
| 断开连接后屏幕变黑 | 正常：协议 §6 规定链路断开自动清屏 |

## 4. 地址与端口速查
| 项 | 值 |
| :--- | :--- |
| ESP32 热点 SSID / 密码 | `ESPNav-AP` / `espnav1234` |
| ESP32 热点网关 | `192.168.4.1` |
| 配网页 | `http://192.168.4.1`（`/`、`/scan`、`/save`、`/status`） |
| 导航数据 TCP 端口 | `8899`（一行一条 JSON；单主机，最新连接接管） |
| 固件：STA 后设备 IP | 串口日志 `STA 连接成功 IP=...` 或配网页 `/status` |
| mDNS（暂缺，需 `espressif/mdns` 组件） | `espnav.local` / `_espnav._tcp:8899` |
