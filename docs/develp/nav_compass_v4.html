EspNav 罗盘改版效果（提案 v4）


显示为 320×240 放大 2 倍。改动点：罗盘移到顶部居中、与道路中轴重合；中心用黄色车头箭头替代红三角；8 方位 + 短刻度；方位与角度显示在中心右侧。

改动说明
罗盘位置右上 → 顶部整行居中（x=160），与道路中轴线重合
方位基准红色三角 → 黄色车头箭头（与车头/道路中轴一致）
方位数量4 → 8：主方位（北/东/南/西）用中文，斜方位用短刻度线
刻度方位文字之间用短竖线填充（每 15° 一个小刻度）
方位+角度从"红三角右侧" → 车头箭头右侧（如 东北 45°）
车头轴线保留；罗盘中心始终与它对齐
下方信息路名 / 转向提示 / 距离 依次下移一行

说明：斜方位若也用中文（如"东北"=32px 宽）会与相邻方位重叠，故按上图做法——8 个方位都有刻度，只有主方位写中文；当前朝向的完整方位词 + 角度显示在中心右侧。
