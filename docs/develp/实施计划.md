# ESP32‑S3‑LCD2.8外置导航显示系统 实施计划
## 项目概述
手机Android/鸿蒙APP接入高德/百度导航SDK，采集导航信息、手机航向、监听微信短信通知；通过 BLE 下发 JSON 报文（ble_protocol.md）；ESP32‑S3接收并渲染至2.8寸LCD 320×240；道路采用长条模拟，不做真实路口几何还原。

硬件：ESP32‑S3 + 2.8寸 SPI LCD(320×240)
软件栈：Android Kotlin；ESP‑IDF；BLE GATT；JSON 报文协议（ble_protocol.md）。

## 阶段1：原型验证（1‑2周）
目标：验证通信链路、模拟器、帧协议。
1. 完善 HTML 模拟器：直行段透视梯形条带 + 路口/环岛/匝道**模板化路况放大图**（近大远小投影、真实走向绿路径叠加）。已产出 nav_sim_v2.html（主仿真，含模板与完整 UI）与 nav_sim_v3.html（整屏模板样例），待浏览器视觉验收后冻结模板观感。
2. BLE 报文协议文档 ble_protocol.md（已完成 V1.6）：JSON 文本帧、GATT FFB0/FFB1/FFB2、按 `\n` 分包重组规则。
3. ESP32‑S3基础工程搭建：LCD驱动调通；实现基础绘图原语；BLE GATT Server基础框架；PC端串口模拟发送帧测试LCD渲染。
输出：
- nav_sim_v2.html（主仿真，含路况模板）/ nav_sim_v3.html（模板整屏样例）
- ble_protocol.md
- ESP32基础固件，可接收串口帧渲染画面。

## 阶段2：ESP32‑S3固件开发（2‑3周）
目标：设备端完整业务能力。
1. 实现BLE接收、数据包分片重组、帧解析、CRC校验。
2. 实现UI状态机：导航页、消息弹窗页；消息弹窗超时逻辑。
3. 对接全部绘图API，保证渲染输出与HTML模拟器像素对齐。
4. 稳定性测试：丢帧、错帧处理；异常BLE断开复位。
5. 模板与透视渲染：将 HTML V2 模板/投影算法（7 类 + PROJ 常量）离散化移植到 ESP32，与模拟器逐模板像素对照。
输出：可烧录完整固件；设备可以正确解析 NAV_FRAME / POPUP_MSG 等 JSON 报文并显示。

## 阶段3：手机APP基础框架开发（2‑3周）
目标：APP基础架构、BLE通信、传感器。
1. Android工程搭建；权限配置；BLE Client模块开发，支持扫描、连接、分包发送 JSON 报文。
2. 航向传感器模块实现，低通滤波。
3. 开发本地WebView预览模拟器。
4. APP构造测试导航帧，不接入地图SDK，直接下发给ESP32‑S3，联调手机‑ESP32‑LCD通路。
输出：APP可以手动生成测试帧，BLE下发，LCD正确显示画面。

## 阶段4：业务模块集成（2‑3周）
目标：接入导航SDK、通知监听。
1. 封装导航抽象接口 NavSource；分别对接高德导航SDK、百度导航SDK；监听导航回调，提取全部导航字段；实现经纬度转overview缩略图坐标；实现路况模板决策与几何生成（机动识别 → turn_dist<200m 附加 road → 平面坐标换算）。
2. 实现NotificationListenerService，捕获微信、短信通知，组装消息帧下发。
3. APP设置页：开关导航上报、消息透传；提示鸿蒙/安卓电池白名单设置。
输出：APP可以真实启动高德/百度导航，实时把导航数据下发ESP32‑S3；消息弹窗功能可用。

## 阶段5：整机联调、优化与BUG修复（2周）
1. 实车测试：BLE稳定性、后台保活、丢帧处理；航向抖动调优；
2. 功耗测试ESP32‑S3；BLE连接功耗；LCD亮度控制；
3. 边界场景测试：导航偏航重算、信号弱、手机锁屏后台运行；
4. 修复UI闪烁、消息重复、BLE断开重连问题。

## 阶段6：交付输出
1. 完整固件源码；Android APP源码；
2. HTML模拟器；全套md文档：协议、规格、实施计划；
3. 烧录说明、APP安装配置说明、硬件接线说明。

## 风险点清单
1. 安卓/鸿蒙后台杀进程：必须引导用户设置电池优化白名单；否则后台BLE、通知监听会停止。
2. BLE MTU分片：大帧必须做分片重组，否则丢数据。
3. 通知监听属于系统权限，用户必须手动开启，无法APP静默开启。
4. 导航SDK网络依赖，离线导航模式下部分字段可用性需要测试。
5. 道路为"条带 + 模板化路口放大图"模拟，不还原真实路口矢量；模板观感需以 HTML V2/V3 视觉验收冻结；环岛出口编号/绕行方向语义按导航 SDK 实测校准。
6. 鸿蒙 4 兼容层：高德/百度 Android 导航 SDK 在鸿蒙 4 上需实测（尤其百度导航）；通知监听依赖"通知使用权"手动开启、后台保活依赖"应用启动管理"，引导缺失会导致后台功能失效。
7. LCD 驱动 IC 假定 ILI9341：实物到货若为同规格（320×240 SPI）其它 IC，需调整 lcd_driver 底层；IC 抽象层已预留。
