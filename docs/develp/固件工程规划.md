# 固件工程规划（ESP32-S3）— B 线：环境清单 + 工程骨架
> 状态：规划文档（2026-09-03，未写码）。依据：实施方案 2.3/2.4、实施计划 阶段1③/阶段2、技术实现路径 §2、ble_protocol V1.8、模板几何规格 V0.3。
> 前置：硬件实物（ESP32-S3 DevKitC-1 N8R2 + 2.8″ SPI LCD）到货后启动；LCD 驱动 IC 假定 ILI9341（实物核验，风险7）。

## 1. 环境搭建清单（Windows 本机，执行顺序）

| 步骤 | 内容 | 验证 |
| --- | --- | --- |
| 1 | 安装 ESP-IDF v5.1+（推荐 v5.1.x 稳定线）。方式：官方离线安装器 esp-idf-tools-setup（含 Python/工具链）或 `git clone --recursive -b v5.1.x espressif/esp-idf` + `install.ps1`（IDF 5.1 需 Python 3.8-3.11） | `idf.py --version` |
| 2 | 每次终端激活：`%USERPROFILE%\esp\esp-idf\export.ps1`（或 IDF CMD/PowerShell 快捷方式） | 出现 IDF 环境提示 |
| 3 | 目标芯片：`idf.py set-target esp32s3`（N8R2：8MB flash + 2MB PSRAM） | 输出 esp32s3 |
| 4 | 串口驱动：板载 USB 转串口（CP210x 或 CH340，视批次）装驱动；`idf.py -p COMx flash monitor` | 串口枚举 |
| 5 | 硬件到货核验：①板型 DevKitC-1 N8R2；②LCD 模块 320×240 SPI、读背面板丝印确认驱动 IC（ILI9341 假定）；③5V/USB 供电；④接线表定稿（SPI SCLK/MOSI + DC/CS/RST + 背光 PWM 引脚）后回填本节附录 | 与实施方案 2.4 引脚表一致 |

首次冒烟路径（分步，任一步失败即定位）：`hello_world`（串口打印）→ `blink`（GPIO）→ lcd_driver 点亮/填充色块 → 串口帧渲染 NAV_FRAME-straight（见 §4 里程碑 M1）。

## 2. 工程骨架规划（`Esp32S3/` 建议目录，对照技术路径 §2 模块）

```
Esp32S3/
├── CMakeLists.txt / sdkconfig.defaults     # target=esp32s3；PSRAM 使能；NimBLE 开启
├── main/
│   ├── app_main.c                          # 启动：BLE 初始化、任务创建、状态机
│   ├── render/                             # 渲染（readRoad C 移植 + UI 层）
│   │   ├── render_nav.c                    # NAV_FRAME 渲染（条带 + readRoad 7 类模板）
│   │   ├── render_message.c                # 弹窗层（3×16 全角折行滚动/置灰/绿字）
│   │   ├── geo.c / geo.h                   # 投影常量 PROJ + scaleAt + fatten 离散化 + ellArcPts
│   │   └── ui_layout.c                     # 分区：主视图 320×160 / 左下统计 / 右下 overview
│   ├── protocol/                           # 帧解析（技术路径 §2 protocol/frame_parser）
│   │   ├── frame_parser.c                  # 环形缓冲按 `\n` 切帧；JSON 解析失败计数 err
│   │   ├── nav_frame.c                     # payload → 渲染结构（点数≤16 缓冲、默认值表 V1.8）
│   │   └── config.c                        # SET_CONFIG/DEV_STATUS（lcd_brightness/dash_speed/…）
│   ├── ble/
│   │   └── gatt_server.c                   # NimBLE：FFB0/FFB1(Write-NoRsp)/FFB2(Notify)
│   ├── lcd/  (或独立 component lcd_driver) # IC 抽象层 + ILI9341 实现（见 §3）
│   ├── font/                               # GB2312 字库 + drawText（见 §3.4）
│   └── display_task.c                      # 30fps 定时重绘 + 虚线 offset 推进（dash_speed）
└── components/                             # （如拆组件：lcd_driver/font 独立，便于单测）
```

任务模型（技术路径 §2.1）：BLE GATT 回调写入环形缓冲 → 解析任务切 `\n` 帧/JSON → 显示任务 30fps（当前帧缓存 + 弹窗 + 信号中断态）。
状态机：`待机`（黑屏）→ NAV_FRAME → `导航`；导航态可叠 `弹窗` 与 `信号中断`（导航态 3s 无帧）；CLEAR_SCREEN 或 BLE 断开（5s 无任何报文）→ 待机清屏（协议 V1.8 §3.7/§6）。

## 3. 关键模块设计要点

### 3.1 lcd_driver（IC 抽象层，风险7 预留）
- 接口（技术路径 §2.3 绘图原语）：`fillRect / drawLine / drawDashedLine / fillPolygon / drawText / drawCircle/ellipse`；
- 抽象：`lcd_driver.h` 定义 ops 结构（init/setWindow/pushPixels/backlight），`ili9341.c` 实现，第二 IC（同规格 320×240 SPI）新增实现文件切换，上层不感知；
- 缓冲决策（实施时验证二选一）：①仅 GRAM、显示任务**分区域重绘**（主视图 320×160 + 弹窗/提示区），虚线流动需每帧刷主视图 → 区域≈320×160×2B≈100KB 量级搬运/帧；②单帧缓冲 320×240×2B=150KB（SRAM 可容纳，N8R2）整帧组装后一次 DMA。**待固件原型实测帧率定稿**（技术路径 §2.1 缓冲策略）。

### 3.2 BLE GATT（NimBLE，协议 V1.8）
- Service `0000ffb0-…`、Write `…ffb1`（Write Without Response）、Notify `…ffb2`；MTU 协商 247（单包 ≤244，保守 240）；
- 主机帧 5-10fps、单帧 ≤2048B；接收端 `\n` 重组；环形缓冲超 4096 清空；
- Notify 触发：DEV_STATUS（GET_CONFIG 应答 / err>0 每 30s 主动上报至清零）、PONG；
- 心跳：PING 2s（主机侧）；5s 无任何报文或断开 → 清屏待机。

### 3.3 protocol：JSON 与字段映射
- cJSON 解析（IDF 组件库自带）；单帧 ≤2048B、解析失败丢弃 + `err++`；
- 渲染结构按协议 §8 提示 + 默认值表 V1.8：数组上限 centerLine/pastCenter/routeCenter/overview/road.pts ≤16；hint 渲染端 ≤9 全角截断；弹窗折行 16 全角/行、可视 3 行、超长滚动（首屏 4.4s/1.4s 逐行/末屏 2.4s）；
- road 未知 type → 忽略 road 走条带（协议 §6 默认值表）。

### 3.4 字库与字形
- GB2312 全 6763 汉字 16×16 + ASCII 8×16 ≈230KB → flash 只读分区；`drawText` UTF-8→GB2312 查表；
- 特殊字形（↑ ｜ … ← → ↺ 等）纳入扩展清单（几何规格 V0.3 附录 A）；缺字兜底占位方块。

### 3.5 渲染（readRoad C 移植，基准 = nav_sim_v2.html readRoad）
- 几何常量与 JS 1:1：`PROJ{cx160,yNear130,yFar20,sFar0.24}` + 底部生长(锚22,k=1.1)；`TPL{main62,side35}`；`RBT{cx160,cy84,r58,b0.40,aIn0.66,bIn0.17,rw0.31,sIn0.62}`；`AZM` 方位角表；`DIRV`；
- 圆/弧离散化：ellipse 按参数角 N 段多边形；方向弧 ellArcPts 32 段（绿路径）、环带 16 段口径需与 HTML 对齐（几何规格 §5.3）；
- 各 type：straight/curve 沿 pts；tjunc/cross 折点 C + dir 支路；fork 静态主路 + 匝道；multi 读 exits（缺省五方向）；roundabout exits+方向弧（O1），pts 优先；
- 逐模板像素对照验收（实施计划阶段2-5）：C 输出 vs HTML 快照（backup/_snap_v2param 已有 14 张基线）。
