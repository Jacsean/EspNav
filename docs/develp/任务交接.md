## 2. 关键设计决策与理由（**设计过程留档**）

> 这一节把"为什么这么做"固化下来 —— 代码注释只覆盖局部，全局理由在这里。

| # | 决策 | 理由 | 出处 |
| :--- | :--- | :--- | :--- |
| 1 | **ESP32 只渲染，不算路** | 手机算力/网络强；换 SDK、换手机都不影响屏幕端 | 实施方案 §2 |
| 2 | **单帧点数上限 16** | 协议约定（帧体积 + 固件缓冲）→ 所以采样必须"按几何重要性取点" | `ble_protocol.md` §3.1 |
| 3 | **行程图采样用 VW 而非"抽拐点"** | 用户提出反例：很长且弧度均匀的弧线**没有拐点**，抽拐点会把它拉直；VW 的面积度量（½·弦长·弧高）天然保留长弧 | `sampling_design.md` §2-3 |
| 4 | **直角拐点要"锁定"** | VW 的固有弱点：会误剪窄尖角（城市直角路口）→ 叠加锁定补偿 | `sampling_design.md` §3 |
| 5 | **主视图用全量点，行程图用采样点** | 需求不同：主视图要"车前 400 m 的局部精度"，行程图要"整条路线像不像" | `架构与数据流.md` §3.1 |
| 6 | **主视图不画"已走/未走路径线"** | 该线随车头朝向投影旋转，观感差（**用户明确要求删除**）；道路走向由模板路表达 | 提交 `34f16b2` |
| 7 | **路面用模板，不用真实路形** | 模板观感稳定；实测"按真实路径画路面"形状不可控（**用户 2026-09 反馈差**） | `进度与路线图.md` open 项 |
| 8 | **到达终点也发固定模板** | 用户期望"方向转 → 罗盘动、道路图案不动"；发 null 会退回 fallback（随车头转） | 提交 `34f16b2` |
| 9 | **黄点用当前定位投影，不按进度取索引** | 采样后点距不均，按索引取点会跳变 | `NavStateMapper.kt` 注释 |
| 10 | **调试开关做成 App 端可切** | 排查"屏幕上某条怪线是谁画的"时不必反复烧固件 | 提交 `be19acf` |
| 11 | **配置写公共下载目录** | SharedPreferences 卸载即清；只有公共目录能在重装后存活（Android 10+ 分区存储需「所有文件访问」权限） | `ConfigFile.kt` 注释 |
| 12 | **`heading` 只驱动罗盘** | 主视图已是"车头朝上"坐标系，旋转在 App 侧完成 | `ble_protocol.md` §3.1 |

## 7. 协作纪律与用户偏好（**照做，别问为什么**）

### 7.1 流程（用户明确定过）

```
用户提想法 → 先只做可行性论证（不写代码）→ 讨论定稿 → 我提示"是否可以实施"
          → 用户明确回复"可以实施" → 才动手 → 自检 → review → 交付
```

- **未授权不实施**；授权请求要**说清"授权做什么"**（具体到文件/行/效果）
- 讨论期间**只读不写**；用户说"暂停/先讨论"立即停止写入
- 不擅自替换方案；有更优解**在讨论阶段说明**
- 每轮结尾单列「**待你做的事**」

### 7.2 代码质量门（**每次改代码后必做**）

1. `python Esp32S3/tools/precheck.py main` → `problems: 0`
2. `python mobileApp/android/tools/kotlin_precheck.py mobileApp/android` → `problems: 0`
3. **必须编译一次**（预检抓不到"字符串跨行/类型不匹配/初始化顺序"——F13/F15 都是这么栽的）
4. 编译错误**写进 `fault_log.md`**
5. **交付 APK 前需真机启动一次**（agent 无真机 → 交付时明确告知用户这一步只能他做）

| 偏好 | 说明 |

## 8. 给下一个"我"的经验（本次会话的教训）

1. **上下文会被压缩 → 重要结论必须落盘**：本任务里有几次"我忘了前面的决策"，靠 `git log` 和文档找回来。
   所以：**每完成一个主题就提交（提交信息写详细）**，并在文档里留"为什么"。
2. **别用 shell heredoc 写源码**（F12，本项目复发 5 次）；用文件写入工具，落盘后必跑预检。
3. **补丁脚本里要产出 Kotlin 的 `\n` 必须写 `\\n`**（F15）—— 预检过了也要编译一次。
4. **交付前真机启动一次**（F13）—— agent 做不到，要**明确告诉用户这一步**。
