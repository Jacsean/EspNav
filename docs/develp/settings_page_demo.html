归类结果（两类都在用同一份）

  • ① 连接：设备地址（IP / 端口）、启动自动连接
  • ② APK 端：导航（起终点 / 城市 / 模拟）、行程预览采样、App 地图默认缩放、行程图卡片、屏幕常亮、日志行数、权限、配置文件
  • ③ ESP 端：屏幕亮度 / 虚线速度 / 动画、底衬可读性（总开关 + 4 项 + 网格）、屏颜色 ×6、地图样式、底图推送（开关 / 间隔 / 亮度 / 对比度）、屏幕翻转（水平 / 垂直）、调试帧过滤 ×5

顺带修正的两处现有缺陷

  • 「set_group_map」标题出现两次（地图样式组 + 默认缩放组）→ 合并到对应归类里
  • 配置文件按钮（授权 / 保存 / 加载 / 删除）原被拆在两组之间 → 归到「配置文件」小节

两方案取舍

  • 方案 A（可收缩分组）：仍是一页到底，能一眼看到全貌；靠展开/收起控制长度。适合"经常跨类对照调参"。
  • 方案 B（Tab）：每屏只一类，滚动最短、点得最少；但跨类调参要来回切。
  • 也可混合：外层 3 个 Tab，内层仍用可收缩小节（ESP 端内容最多，尤其适合）。
