顺带修掉的两处现有缺陷

  • 「set_group_map」标题出现两次（地图样式组 + 默认缩放组）→ 分别归入 ESP 端与 APK 端
  • 配置文件按钮（授权 / 保存 / 加载 / 删除）原被拆在两组之间 → 归拢为一个「配置文件」小节

交互约定

  • 外层 3 个 Tab 固定在顶部，滚动时不动；只有中间内容区滚动；每个 Tab 保留自己的滚动位置
  • 内层小节可收缩，默认只展开最常用的（例如 ③ ESP 端默认展开「屏幕」，其余收起）
确认这个形态后我就改 page_settings.xml（所有控件 id 保持不变，MainActivity.kt 的绑定逻辑基本不动，只加 Tab 切换与小节展开两段逻辑）+ 自行编译验证。本次只动 APK，固件不用重烧。
