## 实现约定（M3 收尾，2026-09-14）
1. **消息分派**：新增 `main/protocol/protocol.c`（`protocol_handle(line, len, send, ctx)`）——承载无关（TCP/BLE 各自提供 send 回调），只做解析+业务动作。
2. **回包**：
   - `PING` -> `PONG`（回显 `ts`）
   - `GET_CONFIG` -> `DEV_STATUS`（携带全部配置 + `firmware_ver` + `err`），并清零 `err`
   - **`SET_CONFIG` -> `DEV_STATUS`**：协议未定义 ACK 消息类型，设备以状态上报作为"已生效"确认（不新增消息类型）
   - `CLEAR_SCREEN` -> 黑屏待机；`POPUP_MSG`/`POPUP_CLOSE` -> 暂忽略（M7 弹窗层）
   - 未知 `msg_type` -> 忽略（协议 §6.2）；缺 `msg_type`（非法帧）-> `err` 计数
3. **生效路径**：`dash_speed`/`anim_enable` 由渲染 tick 每帧读 `config_get()`（下一帧即生效）；`lcd_brightness` 直接调用 LCD 驱动背光接口（PWM 占空）；`popup_timeout` 存配置供 M7 使用。
4. **线程安全**：SPI/帧缓冲**只由显示任务访问**——`render_nav_clear()` 仅置请求标志，实际清屏在 `render_nav_tick()` 内执行；TCP 客户端任务只解析与回包。
5. **连接管理**：单主机"最新连接接管"（新连接到来时 shutdown 旧 socket，旧任务自然退出）；客户端断开 -> 请求清屏（协议 §6）。
6. **预检增强**：`tools/precheck.py` 新增"系统头缺失"检查（如用 `snprintf` 未 include `<stdio.h>`）——本轮即抓出 `json_lite.c` 一处。
